### 🎰 ROULETTE SYSTEM — DATABASE 004

### WEAPON DATABASE — AS 50 ARMAS OFICIAIS

CHEGAMOS ÀS ARMAS! ⚔️

Aqui quero estabelecer uma coisa: uma arma não é simplesmente um objeto que aumenta o dano. Ela pode mudar completamente o estilo de combate do personagem.

Um personagem com força absurda pode ter dificuldade para utilizar uma arma extremamente técnica. Já alguém com MAN elevadíssimo pode transformar uma arma aparentemente comum em algo perigosíssimo.

### 1\. Regras da roleta de armas

Cada arma terá:

* Nome e descrição.

* Raridade e probabilidade individual.

* Buffs e debuffs.

* Dano-base (DMG).

* Alcance (ALC).

* Velocidade de utilização (VEL).

* Durabilidade (DUR).

* Compatibilidade.

* Limitações.

Escalas das armas:

| Grau | Capacidade de dano |
| ---- | ------------------ |
| W0   | Humana             |
| W1   | Sobrehumana        |
| W2   | Edifício           |
| W3   | Quarteirão         |
| W4   | Cidade             |
| W5   | Montanha           |
| W6   | Ilha               |
| W7   | Continental        |
| W8   | Planetária         |
| W9   | Estelar            |
| W10  | Cósmica            |
| W11  | Multiversal        |

A escala representa o potencial máximo de dano da arma quando utilizada adequadamente, não seu dano automático.
